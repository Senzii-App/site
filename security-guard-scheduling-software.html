Frequently Asked Questions

What is security guard scheduling software?

Security guard scheduling software is a digital platform that helps security companies create, manage, and distribute guard shift schedules across multiple client sites. It goes beyond basic calendars by tracking guard certifications, matching guards to post orders based on skills and site requirements, and alerting managers when coverage gaps or compliance risks arise.

How does Senzii handle multi-site security scheduling?

Senzii supports unlimited client sites with independent post orders, coverage requirements, and billing rates. You can assign guards to specific sites, allow cross-site coverage when a guard is qualified, and view real-time coverage across all locations from a single dashboard. Each site can have its own shift patterns, minimum staffing levels, and special requirements.

Can Senzii track guard certifications and licenses?

Yes. Every guard profile stores certifications (armed, unarmed, CPR, first aid, etc.), state licenses, and firearm permits with expiry dates. Senzii automatically flags guards whose credentials are expiring within 30, 60, or 90 days and prevents scheduling guards on posts that require expired credentials — protecting your firm from liability.

How does post-order matching work?

Each client site in Senzii has post orders that define required skills (e.g., armed patrol, access control, fire safety), shift coverage levels, and guard preferences. When you build a schedule, Senzii suggests guards whose qualifications match the post order. If a site requires an armed guard with active shooter training, only guards with both credentials will be recommended — eliminating mismatches that create liability.

Does Senzii support mobile patrol scheduling?

Yes. Senzii supports mobile patrol routes with checkpoint scheduling, estimated drive times between sites, and GPS check-in verification. You can build patrol routes that visit multiple client sites per shift, set minimum time per checkpoint, and receive alerts if a guard misses a scheduled checkpoint.

How does Senzii prevent coverage gaps?

Senzii continuously monitors every site against minimum staffing requirements. If a guard calls in sick or quits, the system immediately flags the gap and suggests qualified replacements from your pool. It also warns you when too many guards are scheduled off simultaneously (e.g., before holidays) and recommends pre-approving overtime or scheduling floaters.
